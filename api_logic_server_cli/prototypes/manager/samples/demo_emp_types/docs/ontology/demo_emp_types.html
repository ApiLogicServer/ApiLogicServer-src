2. Kinds of Employee

Employees are classified two independent ways. Every employee is one kind on the first axis, and may also be military.

By employee type

Exactly one of these:

Commissioned Employee employee type = commissioned

Commission Order records can belong only to this kind of employee.

FieldKind of valueNotes
Base salaryamount
Commission totalamountcomputed by rule “Commissioned commission_total = sum(Order.amount)”

Hourly Employee employee type = hourly

May have a Labor Union. No other kind of employee can.

FieldKind of valueNotes
Hourly ratenumber
Hours workednumber
Union duesamountcomputed by rule “Hourly union_dues = hours_worked * union.dues_rate”

Salaried Employee employee type = salaried

No additional fields. Salary is entered directly.

By military

Independent of the other classification:

Military Employee military = yes

FieldKind of valueNotes
Branchone of: Army, Navy, Air Force, Marines, Coast Guard
Ranktext
Service yearswhole number
