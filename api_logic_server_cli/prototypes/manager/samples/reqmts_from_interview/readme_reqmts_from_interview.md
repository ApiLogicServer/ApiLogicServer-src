This illustrates you can supply incomplete requirements, and request that AI *interview* you to complete them and create a system.

We often call it **RFI:** *requirements from interview*.

This illustrates 2 examples:

* the basic demo for Customer and Orders, and request an interview for encouraging sales of *"green"* products.  Recreate it from `samples/prompts/basic_demo_rfi.prompt`
* a library system

You can examine the reconstructed interview transcipts at `docs/requirements/transacript_reconstructed.md`.
