2. Kinds of Employee

They are classified in independent ways. Each record is exactly one kind on each way that is exclusive, and may also be a kind from the others.

By type

Exactly one of these:

Salaried Employee type = salaried

No additional fields.

Hourly Employee type = hourly

May have one Labor Union. No other kind of employee can.

FieldKind of valueNotes
Hours workednumber
Hourly ratenumber
Union duesamountcomputed hours worked * union dues rate for hourly employees with a union, else 0

Commissioned Employee type = commissioned

FieldKind of valueNotes

By military

Independent of the other classifications:
