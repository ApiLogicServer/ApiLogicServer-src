## Schema Decisions

| Table | Purpose | Notes |
|---|---|---|
| `sys_config` | singleton settings | added `max_hourly_weekly_salary` (5000), `military_stipend_per_service_year` (100); read with `SysConfig.current(session)`, no FK |
| `department` | name, budget | `total_salary` = sum(employee.salary) |
| `labor_union` | name, dues_rate | named `labor_union` because `union` is an SQL keyword |
| `employee` | Single Table Inheritance | discriminator `type` (salaried/hourly/commissioned); independent axis `military` (yes/no); subtype columns nullable; derived: salary, union_dues, commission_total, order_count, military_stipend, total_compensation |
| `order` | sales orders of commissioned employees | customer_name, amount |

DDL: [`database/ddl_emp_types.sql`](../../database/ddl_emp_types.sql). No SQLAlchemy polymorphic subclasses: all rules are on `models.Employee`, branching on `row.type`.

Security: Keycloak; `security/declare_security.py` left as generated by `add-auth`. The one role-dependent business rule
(manager may exceed the budget) uses `Security.current_user_has_role('manager')` inside the Department constraint.

Admin App: `ui/admin/admin-merge.yaml` has the full domain plus `show_when` for subtype fields; `admin.yaml` was not
replaced (needs your approval: back up `admin.yaml` to `admin.yaml.bak`, then copy `admin-merge.yaml` over it).
